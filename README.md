# deighne/homebrew-tap

Homebrew tap for personal CLI tools.

## Installation

```bash
brew install deighne/tap/<formula>
```

## Available Formulas

- **[termcal](Formula/termcal.rb)**: Keyboard-driven terminal calendar built on [caldir](https://caldir.org).
  ```bash
  brew install deighne/tap/termcal
  ```
